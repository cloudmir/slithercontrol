# pocket11(원 가장자리 몸 검사) 구현, 이후 실서버 데이터 중심 개발 · 하루 한도 해제

사용자(2026-09-24, 원 돌기 필터 결함 보고 후) 원문:
> 응 잘 고치고
> 이제부터는 실서버에서 테스트를 해서 실 데이터를 얻자.
> 그게 나을것 같다
> 하루 실행 한계 20판은 이제 리미트를 없앨테니
> 실서버에서 마음껏 테스트를해서 실정보를 모아서 정밀하게 만드는것을 중점적으로 하자

결정:
- pocket11.py(pocket8 상속): 고리가 닫힌 뒤에도 원 중심 거리 < 반경 + 우리 반경 + 적 반경 + 10px인 몸, 그리고 같은 기준의 머리를 계속 검사한다.
  - 유지 기준은 drawn 겹침(0px)이다.
  - pocket7에는 기본값이 같은 coil_edge·coil_keep 속성만 추가했다(pocket7/8 자체 검사 통과).
- 하루 실사이트 한도를 해제한다(live.py MAX_PER_DAY=inf).
- 앞으로 개발 검증의 중심은 실서버 판이며, 이 대화의 지시에 따라 여러 판을 연속 실행한다. 이는 사용자 결정이다.
- 유지하는 조건:
  - 브라우저 1개, 판 사이 30~90초 간격.
  - 오류 시 연속 실행을 중단하고 자동 재접속하지 않는다.
  - 시간 제한 없음, Esc 중단 가능.
  - 닉네임은 i/l 20자.
  - 위장 동작은 하지 않는다.
- 기록 추가: close_trace(drawn 간격 < 30px인 모든 틱의 위치·방향·가장 가까운 적 조각·우리 반경). 실제 충돌 거리를 보정하는 데 쓴다.
- 로컬 시뮬레이터는 회귀 확인용으로만 병행한다.
