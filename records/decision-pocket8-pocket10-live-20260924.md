# pocket8(방어 구간 전체 기록)·pocket10 실사이트 각 1판

사용자(2026-09-24): "둘다 다 실사이트에서 돌려봐". 직전 제시한 두 선택지에 대한 답이다.
- (a) 기록 기능이 붙은 pocket8로 굵은 적 가설 확인.
- (b) pocket10.

pocket10은 로컬 일반 플레이에서 pocket8보다 나빴다(claim-pocket10-local-20260924). 사용자는 이를 고지받은 뒤 실행을 지시했다.

실행 조건:
- Windows Chrome에서 pocket8 1판을 먼저 돌리고, 30~90초 무작위 간격 뒤 pocket10 1판을 돌린다.
- 오늘 14판을 썼으므로 이번이 15·16번째다(한도 20).
- 시간 제한 없음, 사망·오류·Esc 시 종료, 자동 재시도 없음, 브라우저 1개.
- 두 판 모두 defend_trace(방어·원 돌기 중 매 판단의 적 반경·우리 반경·간격·포위도)를 기록한다.
