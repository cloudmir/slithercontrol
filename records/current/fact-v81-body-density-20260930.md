# V8-1 — 몸통 밀도 조건으로 V6 회피 추가

사용자 지시: “V8-1을 만들고 … 내 머리중심으로 일정거리에 지렁이들의 몸통까지 밀도가 높을때도 회피 모드가 발동하도록 하나 추가해줘 … 긴 적들이 붐빌때.” 사용자 선택이다. 삭제된 단일 머리→V4.1 방식은 복구하지 않았다.

구현 원문: ext/pilot.js bodyDensity·v8Choice·v8Step, ext/mod.js observe·홈 버튼·로그, params.json v81_density. 기존 V8의 머리 수 조건 OR 몸통 점유율 조건이면 원본 V6, 두 조건 모두 해제된 상태가 V8_CLEAR_S 동안 지속되면 원본 V1. 원본 V1/V6 판단 함수·거시 경로 함수는 유지하며 V8에서 몸통 조건은 기본 꺼짐.

몸통 점유율은 내 머리 중심 원을 40×40 격자에서 표본화하여 관측된 적 몸통 선분·실제 두께가 덮은 면적 비율을 근사한다. 중복·겹침은 한 번만 세며 몸통 점 수를 밀도로 쓰지 않는다. 머리가 반경 밖인 긴 적도 포함한다. 자기 몸·죽은 적·dying 점을 제외하며 dying 구간을 가로질러 잇지 않는다. 미관측 몸통은 추정하지 않는다. 전환용 몸 관측은 별도로 수집하므로 기존 V1/V6 조작 입력 범위는 유지된다.

설정: V81_BODY_ON, V81_BODY_R 기본450px(100–6000, 25px 단계), V81_BODY_PCT 기본18%(1–80, 1% 단계). 기본값은 구현상 초기 선택이며 실전 최적값이 아니다. 홈 V8-1 버튼은 현재 V8 조정값을 보존하고 몸통 조건만 켠다. 다른 모드에서 선택하면 V8 기본 프리셋을 먼저 적용한다. 내장 v81_density 프리셋도 제공. 홈·조정 화면에서 반경·점유율 조정/저장 가능. HUD·머리 옆에 밀도 표시, trace와 전체 로그에 발동 이유·밀도 저장, 블랙박스에 당시 v8Control 저장.
