# 새 목표 — V2 로직 (사용자 2026-09-28 저녁)

사용자 원문:
> 목표를 다시줄께. 지금 만든거는 그냥 두고 새로운 로직으로 켜면 다른 파라메터를 다 무시하고
> 1. 안죽는 절대 알고리즘을 적용한다 — 감기는것 / 앞에 같은 방향으로 진행하다가 길이 좁아지는것 (돌아나갈수 있을때 돌아 나가야함)
> 2. 누구보다 빠르고 잽싸게 적의 사체(죽으면 남는)을 수집해서 몸을 키운다. 부스터로 누구보다 빨리
> 위 두개만 목표를 강하게 줄테니 한번 제대로 해봐. 개선 테스트 모두 너 맘대로진행. 대신 1등을 목표로 해야함

사용자 진단(같은 날, 사실로 기록): 지금 코드는 목표 지향이 아니라 사망 사례마다 규칙을 덧붙인 수동적 개발이며 파라미터 대부분이 쓸모없다. 어시스턴트 감사: 104개 중 실게임으로 효과 확인 17개(16%), 값 미검증 구조 파라미터 약 35, 가중치 약 25, 미검증 신규 16, 도구 6.

결정:
- 기존 코드·파라미터는 그대로 두고, V2 모드(스위치 하나)를 별도 함수로 만든다. 켜면 V2의 소수 파라미터만 쓰고 나머지는 무시한다.
- V2 설계 원칙: 불변 조건(적 전체의 도달 영역 합집합 밖에 항상 출구를 남긴다)을 매 틱 검사하는 것이 핵심이고, 감김·통로 좁힘은 같은 계산의 두 사례로 다룬다. 잔해 수집은 이 불변 조건을 통과하는 후보 안에서 "먼저 도착" 계산으로 부스트 돌진한다.
- 판정 지표: 감김·통로 사망/10분(목표 0에 가깝게), 큰 잔해 무더기 선점률(우리가 먼저 도착한 비율), 성장 L/분, 판 끝 순위(게임의 rank/of N — 로그에 추가), 생존. 1등 목표를 재려면 10분 상한을 없애야 하므로 V2 판은 상한 없이(사망까지) 돌린다.
- 실게임 테스트는 어시스턴트 재량(사용자 위임).
