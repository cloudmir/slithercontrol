# V4 아키텍처 설계 검토

대상: `decision-v4-architecture-20260930`. 코드 수정 없음.

층 분리, 공통 물리·시간축, 느린 전역 경로와 빠른 근접 회피의 결합은 기존 V4의 0.7초대 지연과 회전 모델 결함을 구조적으로 해결하는 올바른 방향이다. 구현 확정 전 아래 계약을 추가해야 한다.

1. C는 별도 Worker에서 A/B의 불변 스냅샷과 버전 번호를 읽는다. 완료 시 현재 지도 버전이 다르거나 경로 주변 점유가 바뀌었으면 즉시 폐기한다. `나이 ≤0.5초`만으로는 안전하지 않다.
2. 40ms 초과의 부분 결과는 충돌 검사를 끝낸 완전한 경로 접두부만 반환한다. 인증된 접두부가 없으면 D 단독으로 전환한다.
3. 상태당 `최소 비용·최소 시각` 두 극단만으로는 중간 절충 경로를 잃는다. `(도달시각, 선호비용, 최소여유)`의 비지배 라벨을 최대 3~4개 유지하는 bounded Pareto가 필요하다.
4. D 선택은 사전식으로 한다: 몸·벽 비접촉 → 적 도달 위반 0인 후보 → C 경로 추종 → 성장. 적 도달 위반 후보는 모든 후보가 위반할 때만 최소 위반으로 선택한다.
5. A의 몸 기억은 단순 TTL이 아니라 지렁이 ID·선분 갱신·꼬리 소멸을 추적해 중복과 허위 벽을 막는다. D는 매 틱 C 경로의 가까운 구간을 현재 관측으로 다시 검사한다.
6. C 목적함수는 생존 가능 출구와 시간 여유를 1순위, 먹이 가치를 2순위로 명시한다. E 입력은 단일 방향이 아니라 D가 검증한 짧은 시각표시 원호여야 한다.

이 여섯 계약을 포함하면 구현에 들어갈 수 있는 수준이다. 계산 시간 목표는 설계 가정이 아니라 전 프레임 p95·최대치로 통과해야 하는 합격 기준이다.
