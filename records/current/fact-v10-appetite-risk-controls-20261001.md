# V10 먹이 위험 감수 슬라이더·경로별 RISK

사용자 선택: 의미 없는 슬라이더 정리, 위험 감수하며 잔해 수집하는 정도 조절. 추가 요청: 각 라인에 RISK Weight 수치 표시. 이번 판 분석 중단 지시는 유지했다.

빌드 1001-e3606de6. 원본 보존 research/v10_appetite_20261001/before/. 코드·검증·해시는 같은 폴더 manifest.json, final.patch, source.txt.

- V10_FOOD_RISK 0~100, 기본0. 경로 비용 = 차단 위험지수 − (슬라이더/100)×경로상 잔해 접근 이득(0~1). 이득은 가까운 관측 잔해 최대3개 무더기의 질량·경로 선분 접근 거리·도달 시간으로 평가하는 휴리스틱. 보정된 섭취량/사망 확률이 아니다. 0은 차단 위험 우선, 높은 값은 잔해 이득에 한해 위험 허용. 탐색 후보 선별·완료 경로·현재 재검사에 같은 비교 함수를 사용한다.
- 몸통/벽 및 근접 예측 충돌 검사는 계속 적용. 긴 경로 안에서 먹이를 향하는 제어 후보를 포함한다. 위험 감수100도 충돌 경로를 무조건 허용하지 않는다.
- V10에서 V9_FOOD_W 슬라이더를 새 위험 감수 슬라이더로 대체. 기존 V9_FOOD_W가0이어도 V10의 잔해 목표를 끄지 않는다. V9의 해당 설정 동작은 보존.
- V10 부스트 허용 스위치로 수집·탈출 후보를 통합; V9_BOOST_ON 등 V10에 무효/중복인 항목은 V10 화면에서 제외. V10 조정 탭은 실제 사용되는 V10 및 공유 항목만 표시. 다른 버전용 원본 설정·슬라이더 유지.
- V10_LOCAL_MS 슬라이더 범위1~12는 원래 계산 하한12 때문에 계산 허용시간을 바꾸지 않았다. UI·기본/프리셋 정의에서 제거. 실제 초과 기록은 유효 예산과 비교한다. 내부 검증용 상한 override는 유지.
- 각 후보 선의 보이는 위치에 같은 색 RISK 0.xx 표시(0~1, 낮을수록 차단 위험지수 낮음). Worker→화면 전달에서 빠졌던 v10Closures를 연결; 유효한 최신 후보와 동일 순서로 표시한다.

검증: 기능8개 통과(슬라이더에 따른 안전/먹이 선택 전환, 먹이 없는 위험 보상 없음, 선분 먹이 접근·시간 감가, 2229px 경로가 합성 먹이 5.34px 근처 통과 후 계속 전진, 먹이 삭제 시 위험 보상 제거, 벽 충돌 불허, 부스트 끄기, V9 동작). 회귀11개는 지도500ms/근접100ms로 기능 확인; 기존150ms/12ms 검사에서 시간 상한 실패가 있어 기본 예산 성능 통과로 해석하지 않는다. Chromium 3 Worker 기본90ms/12ms 모의 화면에서 경로3개·RISK 표시·슬라이더75 저장/재로드·V9 전환·오류0 확인.
