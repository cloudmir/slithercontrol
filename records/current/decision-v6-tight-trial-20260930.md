# V6 근접 여유 조정 시험

사용자 진술: 먹이를 찾아가지 않고 목적 없이 돌며 위험 회피가 보수적이라고 관찰했다. 사용자는 타이트한 상황까지 파라미터를 튜닝할 수 있어야 한다고 요청했고, 이어 “그럼 좀 조정을 해볼까?”라고 지시했다.

시험 선택: 진행 중 기준선 판을 끝내고 분석한 뒤, 같은 코드에서 V6_MARGIN 10→5px, V6_SAFETY 0.3→0.1초, V6_CLEAR_W 0.6→0.2를 적용한 한 판을 실행한다. 설정 파일 research/v6_tight_arms.json. 각 판 상한 600초. 판 중 의도적 설정 변경 없이 기록한다.

목적: 추가 안전 여유 감소가 근접 통과와 충돌에 미치는 영향 관찰. 성공 기준: 판단 오류 없이 작동하며 근접 통과 표본을 얻고, 충돌하면 마지막 관측과 선택 경로를 분석한다. 한 판씩의 비교는 성능 개선 확정 근거가 아니다.

코드 확인: ext/pilot.js d6fda511…의 v6Route에는 먹이 목표 선택이 없다. v6Step의 먹이 점수는 위험·경로 추종·여유 비교 뒤 최종 비교에만 사용된다. 먹이 추구를 강화하려면 별도 코드 변경이 필요하며 이 시험은 위험 여유만 조정한다.
