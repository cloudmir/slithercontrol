# 제어 정밀성 확보 — 실측 경계 적용 후 5판 단위 반복 (사용자 제안 2026-09-28)

사용자 원문:
> OK 우선 정확한 수치를 산출하고, 이 값을 적용하여 1. 먹이를 가장 많이 먹는 알고리즘 2. 정밀하게 지렁이 사이로 잘 돌아다니도록 (거의 닿을듯 말듯 움직임) 3. 부스터를 효율적으로 많이 사용할것 -> RISK가 높아도 가능한 많은 시도를 하여 제어 정밀성을 확보. … 수정+검증(5판) -> 수정+검증(5판) -> … iteration으로 돌려서 가장 정밀하도록 제어시스템을 확보하였으면함

어시스턴트 의견(사용자에게 답함): 방향 동의. 조건 — 5판 판정은 생존이 아니라 사건 단위 정밀 지표로만(판당 수백 사건이라 5판이면 충분). 지표: (1) 큰 무더기 놓침 비율·잔해 구간 L/분·도달 시간 (2) 몸 옆 통과 때 목표 여유 대비 실측 gap 오차 중앙값, 경계 아래로 들어간 비율, 몸 접촉 사망/통과 100회 (3) 부스트 1초당 L 증가, 부스트 중 사망 비율, 켬/끔 흔들림. 반복마다 수정 1개·가설 1개, 정밀 지표 퇴보 금지. 사망은 크기를 15px로 되돌려 큰 r 데이터를 못 얻으므로 탐침 판과 성장 판을 섞는다. 여유는 경계 + 지연 오차(속도×0.1초; 평행 이동은 작고 가로지르기는 큼)로 속도별로 둔다.
