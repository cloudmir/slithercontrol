# V9 — 몸통 벽 지도·복수 탈출 경로

사용자 선택: “V9으로 새로 만들어봐. 실제 미로 map을 만들고, 적의 몸들을 벽으로 mapping하고, 실제 빠져 나가는 탈출 라우트 여러개를 지렁이 앞에 선정해서 보여주는 식으로 … 지렁이들 사이를 정확하게 빠져나가는 라인”.

구현 빌드 `1001-1d9eee2a`. V9 독립 모드·홈 버튼·프리셋 `v9_maze`를 추가했다. 원본은 research/v9_20261001/before/에 보존. V1·V6·V8 판단 함수 본문 및 물리 함수 불변을 검사했다.

- ext/pilot.js v9World/Route: 관측된 적 몸통 선분과 실제 두께를 벽으로 만들고 내 반지름+여유를 확장한다. 음수 경계 보정으로 보이는 몸보다 벽이 작아지지 않는다. 32px 격자는 연결성·탐색 안내용이며, 실제 경로는 위치·방향·속도·시간을 가진 회전 기동 탐색으로 구한다. 모든 연속 이동 구간을 선분-캡슐 거리와 회전 곡선 여유로 검사한다. 적 머리 직진 예측 및 그 뒤 생성될 몸통도 반영한다.
- v9Step: V8 머리 개수 조건과 무관하게 항상 미로 탐색. 현재 머리에서 모든 후보의 남은 전체 기동을 재생·재검사한다. 막히거나 오래된 경로는 제거하고, 출구를 못 찾으면 짧은 근접 회피만 표시한다.
- ext/mod.js: 벽=얇은 보라 경계, 선택 탈출선=초록 실선, 대안=색상별 점선, 모두 0.5px. 그리는 경로와 실제 조향은 같은 고정 목표각 명령을 사용한다. 전송 이력과 TRACK_LAT를 반영한다. 홈·표시 탭에 지도와 후보선 개별 스위치. V9 반경·목표 거리·여유·후보 수·탐색 시간·머리 여유 슬라이더 추가.
- 기본: 관측 반경1200px, 탈출 목표900px, 몸 여유5px, 후보 최대3(1–5 조절), 탐색8초, Worker 계획 예산100ms, 갱신300ms, 경로 유효기간0.65초. 화면은 관측0.2초 이상 낡으면 후보·벽을 숨긴다. 기본값은 구현 선택이며 실전 최적값이 아니다.

검증 원문 research/v9_20261001/:
1. check.mjs → check.json: 열린 곳3, 통로1, 정면 장벽3, 폐쇄0, U자3 후보. 표본 사이 선분과 회전율 독립 검사 통과. 이 검사는 기하 능력 확인용 예산500ms이며, 기본100ms 성능 결과로 쓰지 않는다.
2. edge_cases.mjs → edge_cases.json: 중심선 간격100px 통로는 통과 불가, 120px 통로는 여유6px로 경로 생성. 낡은 경로 삭제·새 벽 차단·얇은 벽 가로지르기 거절·미래 몸통 거절·현재 머리 재기준화 통과.
3. drive.mjs → drive.json: 기본100ms, 실제 명령 지연을 포함한 반복 조향 모의시험. 좁은 통로/정면 장벽/U자에서 각각4.72/5.24/6.44초에900px 이상 탈출, 접촉0, 최소 여유6/51.53/10.18px. 최초 시험에서 미래 각도 추종과 지연 불일치로 장벽 접촉을 발견해 고정 목표각·명령 이력 재생으로 수정했다(drive_initial.mjs 보존).
4. mock.py → mock.json: 최종 빌드의 실제 브라우저 Worker에서 복수 후보·얇은 선·통로·반경 밖 양 끝점의 긴 몸 관측·표시 스위치·슬라이더·V1 복귀·저장 확인, 페이지 오류0. 문법 검사 통과. 일반 python에는 Playwright가 없어 첫 실행 실패했으며 프로젝트 .venv로 재실행 성공.

한계: 정적 장면과 동일 물리 모델의 로컬 검증이다. 움직이는 적의 임의 회전·부스트, 미관측 몸통, 실제 서버 지연 변동에 대한 안전 보장은 아니다. ‘탈출’은 현재 관측 지도에서 설정 거리까지 도달한다는 뜻이며 전체 포위 밖 보장은 아니다. 탐색 제한으로 가능한 길도 못 찾을 수 있다. V9은 현재 비부스트 탈출 전용이며 먹이 추종을 추가하지 않았다. 신규 실게임은 실행하지 않았다.

적용 상태: ext/ 생성 완료. windows_applied.json의 Windows Chrome CDP 연결은 socket hang up으로 실패해 현재 실행 빌드는 확인하지 못했고 재로드도 하지 못했다. 사용자 확장 재로드+페이지 새로고침 후 V9 선택 필요.
