# 미로 탈출과 근접 회피 분리

사용자(2026-09-30): 기존 화면과 사망 상황 분석 데이터를 기반으로 미로를 만들고 그려 실제로 탈출하며, 근접 회피는 별도 알고리즘으로 만든다.

합의 구조:
- 거시 미로층: 기록과 현재 관측으로 몸·벽·사망 경계를 반영한 세계 좌표 지도를 만들고, 통과 가능한 틈·통로·출구를 연결해 인증된 가이드라인을 반환한다.
- 실시간 근접층: 현재 관측에서 짧은 실제 회전 원호를 연속 검사하고, 거시 경로를 따르되 충돌 위험이면 즉시 회피·재탐색 요청한다.
- 표시는 출구까지 인증된 경로, 검증된 부분 경로, 경로 없음 상태를 구분한다. 화면의 선과 실제 제어는 같은 경로 계약을 사용한다.

코드 수정·빌드는 기존 결정에 따라 사용자의 명시적 "수정" 지시 후 진행한다.
