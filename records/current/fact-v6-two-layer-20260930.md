# V6 이중층 미로 탈출 구현·오프라인 검증

사용자(2026-09-30): 기존 화면·사망 자료로 2차원 미로를 만들고 그려 탈출하며, 근접 회피를 별도 알고리즘으로 구현하라고 지시했다.

구현 빌드 `0930-ae56343a`: `ext/pilot.js` SHA-256 `d6fda511…`, `ext/mod.js` `4180bd32…`, `params.json` `ed6e890c…`.

- 거시층: 별도 Worker가 400ms마다 몸·벽·적 도달 시각이 포함된 48px 세계좌표 격자를 탐색한다. 출구 인증 경로와 안전한 부분 경로를 구분하며 계산 상한은 60ms다.
- 근접층: 매 틱 현재 몸 위치만 사용해 1.1초 연속 원호 14개를 검사한다. 충돌·적 도달 위험을 먼저 피하고, 안전 후보 안에서 거시 안내선을 공간적으로 추종한다. 경로가 바뀌거나 낡으면 즉시 폐기하고 재탐색한다.
