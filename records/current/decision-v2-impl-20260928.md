# V2 구현 — 시간 여유(TTD) 계획 (2026-09-28 저녁, 빌드 0928-001b56c8 계열)

사용자 원칙(같은 날 대화): 1.2초 같은 제약 없이 전체를 본다 / 적 전부의 몸·머리·각도·속도로 도달 영역을 계산해 다가오기 전에 비킨다 / 모든 머리는 언제든 부스트한다고 가정 / 예외(관측 밖·같은 틱 정면·서버 지연·스폰 직후)는 "절대"에서 제외 / 결정이 필요하면 물어볼 것.

구현(ext/pilot.js v2Step, V2_ON이면 다른 설정 무시):
- 후보: 목표 방향 24개(15° 간격) × 부스트 2 = 48. 경로: 명령 지연 0.1초 동안 이전 명령 유지 → 최대 회전율로 목표 방향까지 → 그 뒤 세 갈래(직진·좌호·우호, 회전율 절반) 중 최선. 0.1초 간격으로 V2_H(5초)까지 전개.
- 정적 여유 ttdS: 경로가 몸(경계 보정 반영)·벽에 V2_MARGIN(10px) 안으로 닿는 첫 시각.
- 머리 여유 ttdH: 어떤 적 머리든 그 점에 우리보다 먼저 도달할 수 있는 첫 시각. 도달 시간 = max(이동, 회전/회전율). 이동은 부스트 중이면 434px/s, 아니면 순항 0.3초 후 부스트. 회전이 V2_CONE(120°)보다 크면 제외(먼저 도는 것이 보이므로 다음 틱에 반영됨).
- 선택: (1) 정적 계층 — ttdS ≥ min(V2_TOKS 3초, 최대−0.2) (2) 머리 계층 — ttdH ≥ min(V2_TOK 2.5초, 최대−0.5) (3) 목적 = 경로 위 먹이(3초까지, 시간 할인) + 잔해 무더기(sz≥REMAINS 250px 셀, V2_HEAPMIN 60) 도달×(경쟁 머리보다 먼저면 1, 아니면 0.25) × V2_HEAPW − 부스트 비용 V2_BCOST + 머리 여유 V2_WTTD/초 + 같은 방향 유지 V2_HYST.
- 로그 열 ttd·ttds·ttdh·v2obj, 판 기록에 rank·best_rank(HUD 순위). 판단 시간 재생 p50 17ms·p95 25ms.

오프라인:
- 재생 900프레임(붐비는 판): 정적 여유 p50 5초(전 구간), 머리 여유 p50 1.4초(붐비면 모든 머리를 부스트 가정하면 여유가 짧음 → 계층 선택으로 최선을 고름), 명령 60° 급변 0.
- 재주행 오라클(research/v2_rollout.mjs, 사망 8초 전부터 V2로 조종, 적은 기록대로 재생·무반응): 33건 중 생존 V2 기본 23(70%), V2_BCOST 60 26(79%), V2_CONE 120 26(79%); 기존 채택 파일럿 22(67%). 한계: 기록된 이웃(1150px)을 벗어나면 빈 공간으로 보여 관대함(이탈 중앙값 600~1300px). 실게임이 판정.
- 기본값 확정: V2_BCOST 60, V2_CONE 120, 나머지 위와 같음.
