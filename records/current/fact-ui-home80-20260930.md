# 홈 버전 버튼·슬라이더 압축 및 폰트80%

사용자 원문: “Home 의 Control Profile의 V1~V8 까지 작은 버튼으로 만들어 (V1) (V2) ... 마우스 오버하면 설명이 나오도록하고. 아래 슬라이더는 조정탭의 슬라이더 수준으로 높이를 작게 조정해. 전체 폰트는 80% 로 다시 줄여보자”. 사용자 선택으로 기록한다.

원문 코드 ext/mod.js: 기존 선택 동작을 유지하며 버튼 이름을 V1·V2·V3·V4·V4.1·V5·V6·V7·V8로 축약, 설명은 title 툴팁. 버튼24px 높이·한 줄(좁은 화면은 줄바꿈). 홈 숫자 제어는 첫 줄 제목·값, 둘째 줄 전체 폭 슬라이더. 아이콘·상시 설명을 숨기고 설명은 행 툴팁으로 이동. 기존 토글 동작 유지. CSS의 명시적 폰트 크기와 MOD 캔버스 텍스트 크기를 종전100%의80%로 변경. 전체 패널 scale 사용하지 않음.

검증 원문 research/ui_home80_20260930/result.json·home.png: 버튼9개 한 줄·각 설명 존재, 버튼 전환과 숫자 슬라이더 적용 확인. 대표 폰트12/14/12/10/9.5px→9.6/11.2/9.6/8/7.6px. 홈 행47.42px, 조정 행43.91px, 홈 슬라이더340px. 메뉴6개 가로 넘침 없음·작은420px 화면 확인·페이지 오류0. 재로드 검증은 기존200ms 저장 지연 전에 재로드하여 처음 홈 선택을 잃었고, 저장 완료를 기다린 최종 검증 통과. V8 판단 파일 원본과 동일.

실제 페이지: research/ui_home80_20260930/windows_live.json·apply_live.py. 현재 CSS와 버튼·툴팁 DOM 갱신을 적용했고 상태·설정값 동일 확인. 당시 패널 접힘으로 buttons=[]·font=null이며 실제 패널 수치는 미측정. 다시 열거나 렌더링하면 DOM 갱신 적용. 캔버스 글자 크기 변경은 신규 전체 코드가 로드될 때 적용된다. 페이지 재시작·신규 게임 없음.
