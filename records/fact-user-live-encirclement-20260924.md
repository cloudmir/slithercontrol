# 사용자 실사이트 관찰 — 포위 후 사망

사용자는 staged coil 실사이트 첫 판 직후 “지금 포위되서 죽었는데, 포위되면, 죽지 않는 구간으로 계속 반복해서 돌수 있을까?”라고 말했다.

확정 범위는 사용자가 포위 상황을 관찰했다고 진술했다는 사실이다. 원문 월드·영상으로 사망 원인을 독립 확인했다는 뜻은 아니다. 포위 내부의 회전 가능한 공간을 이용해 반복 회전하는 방어 동작의 가능성을 질문했다. 무조건 생존 보장이나 새 구현 착수 지시로 간주하지 않는다. 평상시 채집·회피, 생존 우선 목표는 유지한다.
