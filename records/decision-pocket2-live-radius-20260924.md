# pocket2 실사이트 1판 — 몸 굵기 실측·스크린샷 확인

사용자: “실제로 확인을 해봐야 하지 않을까?” → 실측 방법 제안 후 “돌려서 확인을 하고, 실제 스크린샷같은것으로 확인도 해야 하지 않나?”

직전 pocket2 판(14:16:39)은 시작 약 20초 뒤 제어 프로세스가 세션 종료로 꺼져 무조종 상태로 사망했다(알고리즘 성적 아님, status=error로 정정). 이번 판을 위해 추가한 것:
- 명령이 1.5초 이상 끊기면 게임 페이지를 떠나는 안전장치(로컬 모의 페이지 테스트 통과).
- 매 판단의 모델 간격(머리 ↔ 가장 가까운 적 몸, 반지름 14.5×sc) 기록: 판 전체 최솟값과 마지막 3초.
- 0.5초 간격 절반 크기 JPEG 스크린샷: 최근 8장(사망 직전)과 간격 15px 미만 근접 장면(최대 30장) 저장, 각 장의 화면 변환값(gsc, view_xx, view_yy)도 함께 기록. 전체 크기 캡처는 Windows 중계에서 명령을 최대 147ms 지연시켜 절반 크기로 바꿈(최대 34ms).
- 제어 프로세스는 세션과 분리(setsid)해 실행.

오늘 10판 중 7번째. 조건: 브라우저 1개, 최대 600초, 사망·오류·Esc 시 종료, 자동 재시도 없음. 1판의 결과는 굵기 추정의 소수 표본이다.
