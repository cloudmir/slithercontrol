# 학습된 회피 PPO 실사이트 1판 요청

사용자: "그럼 지금까지 학습된 모델을 브라우져에 띄워봐"

직전 일반 Chrome 실사이트 관찰 맥락에 따라 학습된 회피 PPO를 연결해 추가 1판 실행하도록 해석한다. 이번 조회 시 최신 저장 모델 ppo_059392.zip을 고정하여 사용한다. 이후 저장 모델로 실행 중 교체하지 않는다. 최종 검증으로 선택된 모델이라는 뜻은 아니다. 기록상 7회 다음 1회 예외이며 기본 한도는 유지한다. 안전장치나 플래너로 행동을 교체하지 않는다. 600초 상한, 단일 화면 표시 정식 Linux Chrome, 사망·오류·Esc 종료, 자동 재시도 없음. 학습 과정과 기존 모델은 보존한다.

연결 구현: live_active.py에 recovery_model 선택 인수 추가, 모델 경로·해시·신경망 소스 해시 기록. 기본 제어 주기 2/30초와 두 관측 입력을 사용한다. 실사이트의 정확한 명령 큐와 서버 지연은 미확인이므로 이를 알고 있다고 가정하지 않는다.
