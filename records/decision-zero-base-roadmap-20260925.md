# 제로 베이스 1.a~4.c 단계별 완료 지시 (2026-09-25)

사용자: "단계별로 계속 진행헤서 아까 내가 말한 4C까지 완료해."
근거 요구: fact-user-zero-base-plan-20260925(1.a~4.c).

진행 원칙:
- 단계마다 목적 하나, 성공 기준, 결과를 records/에 남긴다. 실서버 판은 목적 하나만 잰다(decision-live-test-single-purpose-20260925).
- 측정 도구는 probe.py(1.a), measure.py(1.b)를 쓴다.
- 주행 제어기는 새 파일 pilot.py 하나로 만든다. 단계별 기능을 여기에 쌓는다.
  - 안전 핵심: 방향×(보통/부스트) 후보, 실측 사망 간격, 실측 부스트 속도.
  - 2.d 전체 맵 탈출.
  - 3 공격 인지·회피·반격.
  - 4 먹이, 잔해 부스트, 근접 경쟁.
- 각 기능은 자체 검사(명령 지연 포함) 통과 후 실서버에서 그 기능 하나를 판정한다.

단계 순서:
1. 1.a 두께별 사망 간격 → 1.b 부스트 속도·가속 → 1.c 틈 통과 시험 기준.
2. 2.a 지연 측정·단축 → 2.b 필요성 판정 → 2.c 부스트 규칙 → 2.d 전체 맵 탈출.
3. 3.a 공격 인지 → 3.b 반대 방향 탈출 → 3.c 정밀 반격.
4. 4.a 부스트 비용 규칙 → 4.b 잔해 부스트 → 4.c 근접 경쟁 먹기.
