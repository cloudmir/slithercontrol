# PPO에 안전장치를 추가한 실사이트 1판 요청

사용자 직접 지시: "안전장치 넣어서 다시 띄워봐"

직전 ppo_059392.zip 모델을 유지하고 실행 시에만 brain.Planner.shield의 충돌시간·상대기동위험 비교 규칙을 추가한다. PPO의 정확한 26개 행동을 평가 후보에 포함하고 기본 플래너의 탈출 방향도 유지한다. 안전장치 개입 횟수를 기록한다. 이 실사이트 판은 PPO 단독 성적과 구분한다. 학습 환경·모델·기존 신경망 코드는 변경하지 않는다. 안전장치가 모든 충돌을 막는다고 보장하지 않는다.

기록상 8회 다음 추가 1회 요청으로 해석한다. 이번 한도 예외만 적용하고 기본 일일 한도는 유지한다. 정식 Linux Chrome 화면 표시 1개, 600초 상한, 사망·오류·Esc 종료, 자동 재시도 없음. 기존 판 종료를 확인하고 30~90초 무작위 최소 간격을 충족한 뒤 시작한다.
