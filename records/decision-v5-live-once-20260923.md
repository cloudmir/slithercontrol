# v5 실사이트 1판 검증 승인

사용자: "시뮬레이터가 아니라 실제 사이트에서 한번 검증해보자.. 띄워봐."

직전 대화에서 관찰하던 active v5를 화면 표시 브라우저로 실사이트에서 1판 검증하도록 승인했다. 최대 600초, 브라우저 하나, 사망·오류·시간 상한 시 재접속 없이 종료. 기존 일일 5판 한도를 유지한다. 현재 live 로그에는 오늘 3판이 기록되어 있어 기록상 남은 한도 2판 중 1판을 사용한다. 과거 탐색 사용 이력 전체가 이 로그에 들어 있다는 뜻은 아니다.

기존 live.py에는 v5 연결이 없어 독립 live_active.py를 추가했다. v5 뇌·시뮬레이터·학습 소스는 변경하지 않는다. 서버 지연은 실측 전이므로 v5 기본 0.10초 가정임을 명시하고 정확한 시뮬레이터 명령 큐가 실사이트에도 알려졌다고 가정하지 않는다. 실전 상태 원문은 보관하지 않고 횟수 제한·최소 결과 요약만 저장한다. 이번 실사이트 승인은 이후 무제한 실사이트 실행이나 학습 승인이 아니다.
