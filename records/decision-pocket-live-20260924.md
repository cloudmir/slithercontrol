# 포위 방어 실험 모델 실사이트 1판 요청

사용자 “실제 게임으로 띄워봐”는 직전 구현·검증한 pocket 모델을 실제 화면에서 1판 실행하라는 지시로 해석한다. 로컬 일반 플레이에서 열화한 실험 모델이며 기본 coil을 영구 교체하는 요청은 아니다. pocket.py 자체는 시험 버전을 유지하고 live_staged.py에 선택 연결만 추가한다.

닉네임은 앞선 사용자 지시대로 소문자 i/l 무작위 20자. 단일 화면 표시 브라우저, 최대 600초, 사망·오류·Esc 종료, 자동 재시도 없음, 하루 5판 한도 유지. 실행 전 확인한 오늘 로그는 staged coil 1판으로 이번은 기록상 2번째다. 직전 게임은 13:01:49 시작·102.9초 후 종료하여 현재 13:28 이후 기준 최소 대기 90초 이상 지났다.

서버 지연 100ms는 기존 관측 연결의 가정이며 실측하지 않았다. 실전 상태·영상은 저장하지 않고 횟수 제한과 최소 결과 요약·소스 해시만 남긴다.
