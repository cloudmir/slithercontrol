# 사망 직전 상황에서 회피 학습 착수

사용자: "죽었을때 상황을 입력으로 넣고 회피하는것을 핟습 시켜봐"

사망 직전 상황을 활용한 회피 학습·로컬 검증을 승인했다. 앞선 안전장치 없는 강화학습 논의를 반영해 새 정책은 조향·부스트를 직접 결정하고 안전장치가 행동을 교체하지 않는다. 기존 코드와 모델을 보존한다. 실사이트 실행은 포함하지 않는다.

실행 설계: 저장된 v5 사망 시드의 월드를 재현해 사망 수 초 전의 전체 월드·난수·명령 큐를 저장한다. 관측 기록만으로 상대를 고정 재생하는 근사를 실제 반응형 시뮬레이터로 혼동하지 않는다. 원본 사망 사건 단위로 학습·검증·시험을 분리하며 인접 프레임을 서로 다른 분할에 섞지 않는다. 원래 사망 시점 이후까지 회피하는 단기 평가와 새 시드의 장기 생존/활동 평가를 구분한다. 생존·성장·중간 혼잡 목표는 유지하며 단기 회피 개선을 10분 완주율 90% 달성으로 보고하지 않는다.
