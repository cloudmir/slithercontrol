# 기존 제어기를 고치지 않고 새 알고리즘 적용

사용자 직접 지시: "고치지 말고 새로 알고리즘을 적용할것".

현재 개선 작업의 구현 방식을 변경한다. 기존 제어기와 학습 모델은 보존하고 별도의 알고리즘을 설계한다. 기존 코드는 실패 분석, 입출력 및 시뮬레이터 연결 확인을 위해 읽을 수 있다. 기존 프로젝트 목표(생존 우선·성장 차순위, 중간 혼잡 활동 조건, 긴급 일시 이탈 허용)는 유지한다. 실사이트 실행 지시가 아니다.

구체적인 새 알고리즘과 대규모 실행 계획은 아직 사용자 미확정이다. 현재 턴에서는 코드 변경과 실험을 시작하지 않았고, 설계 제안 후 확인받는다.
