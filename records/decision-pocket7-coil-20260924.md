# pocket7: 기본 원칙 “적 몸에 닿지 않기” — 정밀 원 고수, 정확한 몸 굵기

사용자 직접 지시(2026-09-24): “기본에 충실하게 / 안 닿도록 설계를 하고 꼼꼼히 검증해 / 어차피 조여온다해도 적 몸에 안 닿으면 되는거잖아 / 실제 적 몸톤 계산도 정확하게하고”

설계(pocket6 보존, 새 pocket7.py):
- 몸 굵기: 적 몸은 그려진 반지름 14.5×sc의 캡슐, 우리 머리도 그려진 반지름. 추가 여유 없음. 실측(생존 중 그려진 간격 −16px·−4px 관측)상 그려진 굵기는 실제 충돌 판정보다 넓거나 같아 안전 쪽.
- 원(최대 회전 = 정확한 원) 시작: 포위되고 출구가 없을 때, 1.25바퀴 동안 정확 간격 6px 이상이면 시작.
- 원 고수: 한 바퀴 이상 돌고 몸 길이가 원 둘레 이상이면 ‘고리 완성’. 완성 뒤에는 머리가 이미 깔린 자기 몸 위를 되풀이하므로, 원 안쪽으로 들어온 몸·머리만 위협으로 계산(바깥 적 몸은 우리 몸에 닿지 않은 채로만 깔릴 수 있음). 정확 간격 2px 이상이면 계속 돎. 실제 접촉이 예측될 때만 pocket6의 최선 경로와 실제 접촉 시간을 비교해 0.2초 이상 오래 버틸 때만 이탈.
- 탈출: 원을 도는 동안에도 계획 층을 갱신하고, pocket6이 안전한 출구 경로(exit)를 찾으면 원을 풀고 탈출.
- 새 합성 시험 ‘squeeze’(pocket_scenarios.py): 적 고리가 초당 7px씩 조이되 우리가 깐 몸에 닿기 직전(0.5px)에서 멈추고 다시 넓어지지 않음(실제 포위 적의 제약). 기존 ‘shrinking’(몸을 뚫고 40px까지 축소)은 물리적으로 불가능한 장면.
- 자체 검사: squeeze 2시드 60초 생존(최근접 정확 간격 0.4px, 접촉 없음), closed·intruder·opening(탈출) 통과. pocket5·pocket6은 squeeze 2시드 모두 17.7·21.0초 사망(원 포기 후 충돌) — 실사이트 pocket6 사망 재현.
- 검증 계획: 합성 9종×4시드, 일반 16판(80100–), 어려움 난이도, 판단 시간, 이후 실사이트 1판.
