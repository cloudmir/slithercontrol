요구 4축:
1. 죽는 조건을 정확히 파악한다.
   - 1.a 지렁이 두께별로 어디까지 접근하면 죽는지 확실한 데이터를 얻는다. 딱 붙어서 같이 주행할 수 있을 정도의 정밀도와 상세 컨트롤이 목표다.
   - 1.b 부스트 속도 데이터를 얻어 상대의 기습 부스트를 예측한다.
   - 1.c 합격 기준: 다른 지렁이들 사이를 아주 정밀하게 빠져나가는 테스트 시나리오.
2. 컨트롤 정확도를 높인다.
   - 2.a 화면 읽기부터 로직, 실제 제어까지의 시간을 최대한 단축한다.
   - 2.b 단축이 어려우면 브라우저 플러그인까지 시도한다.
   - 2.c 부스트를 효율적으로 쓴다. 회피할 때 제대로 쓰는 것을 못 봤다.
   - 2.d 국지적 판단이 아니라 전체 화면 맵 기준으로 방향을 정한다. 감싸일 때는 감싸는 적의 반대 방향으로 빠르게 빠져나간다.
3. 공격을 받을 때 빠르게 회피하거나 반격하는 모드를 갖춘다.
   - 3.a 현재는 공격 받는 것 자체를 인지하지 못한다.
   - 3.b 회피할 때는 반대쪽으로 빠르게 빠져나가야 감기지 않는다.
   - 3.c 공격 받을 때는 정밀 제어가 필요하고, 그래야 반격이 가능하다.
4. 먹이 효율을 높인다. 현재 효율은 거의 0이다.
   - 4.a 부스트는 꼬리를 줄이므로 먹이가 많거나 효율이 높을 때만 쓴다.
   - 4.b 다른 지렁이의 잔해가 보이면 거의 무조건 부스트로 최대한 먹는다.
   - 4.c 경쟁적으로 먹을 때는 거의 닿을 만큼 접근하는 부스트와 미세 컨트롤이 필요하다.
