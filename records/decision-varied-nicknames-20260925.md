# 닉네임 생성 형식 다양화

사용자 직접 지시:
> 지금 닉네임 수정을 하고 있었는데, 일반사람들이 패턴을 알아채지 못할 만큼만 생성하게 만들어줘. 너무 랜덤이면 그것도 저녀석이 그 패턴이다라고 알아챌수 있으니.

반영: run_live.py의 nickname()을 고정 길이 소문자 8개 무작위 문자열에서 읽기 쉬운 짧은 이름·단어·수식어와 단어 조합으로 변경했다. 길이, 대소문자, 구분자, 숫자 유무를 다양화한다. 같은 프로세스에서 최근 64개 이름의 대소문자 무시 중복을 피한다. bot/ai 포함 금지는 유지한다. 다른 플레이어가 동일 사용자임을 알아채지 못한다는 보장은 하지 않는다.

대체 관계: decision-legacy-cleanup-nick-20260925의 '짧은 단어 + 두 자리 숫자' 형식만 이번 사용자 지시로 대체한다. 이력의 다른 결정은 변경하지 않는다.

검증: 실제 run_live.py에서 관련 상수와 함수를 AST로 추출해 브라우저 없이 2,000개 생성. 길이 1~24, 허용 문자, 최근 64개 중복 방지, 금지 문자열 제외 확인 통과. 관측 길이 3~16자. 프로세스 재시작 간 중복 방지는 제공하지 않는다. 실사이트 실행 없음. 다음 판 이름 생성부터 적용한다.
