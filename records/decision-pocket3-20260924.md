# pocket3: 생존 여유·먹이 무더기 추적·죽은 지렁이 먹이 가중 + 실사이트 1판

사용자 직접 지시(2026-09-24): “수정해서 잘 안죽게 만들자. 그리고 먹이는 모여있는 먹이를 보면 빠르게 그쪽으로 이동해서 먹는것. 그리고 다른 지렁이가 죽으면 큰 먹이들이 많이 나오는데 이것을 가중치 높게 먹도록 설계를 해줘. 수정하고 다시 실제 띄워서 테스트해봐. 지금처럼 스크린샷 찍어서 사후 검증도 할것”

구현(pocket2는 대조군으로 보존, 새 pocket3.py):
- 생존: 적 몸 반지름 +6px(직전 실전 사망 시 모델 간격 +5.5px, 1표본). 실행기는 최근 판단 간격이 설계값(66.7ms)보다 길면 그만큼 명령 지연 가정을 늘림(최대 +0.3초).
- 먹이 무더기: 900px 이내 먹이를 100px 칸으로 묶어 가중 질량/(거리+200) 최대 칸을 목표로, 접근 진행도 가점. 250px보다 멀고 먹이량이 이동 부스트 비용의 2배를 넘으면 정적 여유 50px 이상 안전 부스트 후보로 달려감.
- 큰 먹이: 먹이 가치 가중 value^1.5.
- 실전 기록: 판단마다 먹이 수·최대 크기·모드·부스트·목표 무더기, 무더기 추적 스크린샷(최대 20장), 근접·사망 직전 스크린샷.

로컬 비교(시드 76100–76103, 보통, 120초, runs/pocket3_normal01): 120초 생존 pocket2 3/4, pocket3 4/4. 평균 순성장 pocket2 4114, pocket3 2698. pocket3 76103은 방어 모드(tight_coil 481회 등)가 길어 성장 635. 판단 시간 p95 최대 107ms(4개 병렬 실행 측정). 4판 표본이라 우열 판단 불가.

실사이트: Windows Chrome 1판(오늘 10판 중 8번째), 사용자 지시에 따름. 조건: 브라우저 1개, 최대 600초, 사망·오류·Esc 종료, 자동 재시도 없음. 실사이트 먹이 크기 단위는 미확인이며 무더기 임계값 15는 시뮬레이터 단위 기준 가정이다.
