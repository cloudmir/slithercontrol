# 새 몸체 추종 모델 실사이트 1판 및 닉네임 규칙 변경

사용자: “그럼 실제 게임화면에서 테스트를 해봐”, 이어서 “아이디는 i 와 l 둘다 소문자를 랜덤으로 20자.. iliiiillllii 이런식으로 만들어”.

직전 시뮬레이터의 staged coil 모델을 화면 표시 브라우저에서 실사이트 1판 실행하도록 승인했다. 닉네임은 소문자 i/l만 무작위 20자로 생성한다. 종전 그리스 신화+행성 규칙은 이 새 지시로 대체한다. 자동화 탐지 우회 동작 요청으로 확대 해석하지 않는다.

최대 600초, 단일 브라우저, 사망·오류·Esc 종료, 재시도 없음, 하루 기본 한도 5판 유지. 이번 조회에서 2026-09-24 사용 로그 0판. 원본 제어기와 모델은 그대로 두고 live_staged.py에 자기 몸 좌표 전달을 추가한다. 서버 지연은 미측정이며 관측 목표 방향을 100ms 유지하는 가정으로 입력 큐를 구성한다. 실제 서버 명령 큐를 알고 있다는 뜻이 아니다. 실전 상태 원문 저장 없이 최소 결과 요약과 모델 해시만 저장한다.
