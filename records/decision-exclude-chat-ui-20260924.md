# 잘못 보낸 채팅 앱 UI 요청을 슬리더 프로젝트에서 제외

사용자: “다른 세션이었네, 위에 대화 3개는 무시하고, 실제 테스트 결과는 어때?”

직전 탭 제거·포커스 제목 배경 변경 및 적용 요청은 다른 세션에 보낼 내용이었다. 이 프로젝트의 활성 작업·요구사항에서 제외한다. 기존 패치나 이력 파일을 삭제하라는 뜻은 아니며, 다른 프로젝트에서도 해당 기능을 취소했다고 확대 해석하지 않는다.

현재 요청은 슬리더 테스트 결과 설명이다. 새 실험·실사이트 실행 승인이 아니다. 기존 슬리더 생존·성장 목표는 유지한다.
