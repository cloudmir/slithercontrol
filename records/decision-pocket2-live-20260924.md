# pocket2 실사이트 1판 (Windows Chrome)

사용자: “개선한것을 실제 사이트에서 보자” (일반 플레이 로컬 비교가 중단·미완료임을 고지한 뒤의 답).

pocket2를 Windows Chrome에서 실사이트 1판 실행한다. 오늘 한도 10판 중 6번째. 합성 포위 48판만 완료했다(계속 조여오는 포위에서 pocket2 평균 생존 40.9초, pocket 49.7초). pocket2의 반응형 일반 플레이 검증은 아직 없다. 조건: 브라우저 1개, 최대 600초, 사망·오류·Esc 시 종료, 자동 재시도 없음.
