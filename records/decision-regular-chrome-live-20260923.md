# 일반 Chrome 실사이트 추가 1회 요청

사용자 직접 지시: "일반 크롬 브라우져로 열어서 테스트해보자.."

수정된 active v5를 설치된 일반 Google Chrome으로 실행해 1판 검증한다. 기존 기록상 5회 사용 뒤의 명시적인 추가 테스트 지시이므로 이번 1회만 한도 예외로 해석하고 사용자에게 알렸다. 기본 일일 한도를 영구 변경하지 않는다. 최대 600초, 화면 표시 브라우저 하나, 사망·오류·Esc 시 종료, 자동 재시도 없음. 기존 개인 Chrome 탭이나 프로필에 변경을 가하지 않고 별도 테스트 프로필을 사용한다. 새 PPO 모델 테스트나 추가 학습 지시로 해석하지 않는다.
