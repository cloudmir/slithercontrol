# pocket3 기반 재출발 — 실서버 1판 후 문제점 추출

사용자(2026-09-24):
- "시뮬레이터때문에 노이즈가 누적되었다면, pocket3 을 베이스로 아주 중요한 내용만 추가해서 다시 실서버 기준으로 튜닝하는것이 낫지 않나?"
- 이어서 "10판은 너무 많으니, 1판만 돌려보고 바로 문제점을 뽑아내보자".

결정:
- pocket3(수정 없음)을 Windows Chrome 실서버에서 1판 돌린다. 블랙박스·근접 기록은 붙인다.
- 사망 원인·문제점을 뽑아 다음 수정을 정한다.
- 10판 비교 방식은 사용자가 채택하지 않았다. 판 사이 변동이 커서 1판 결과는 성능 비교 근거가 아니며, 문제점 발견용으로 쓴다(고지함).
- pocket6~12의 추가 기능은 실서버 증거가 있을 때만 다시 넣는다.
